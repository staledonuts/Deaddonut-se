## A chill game about fishing for the big catch!
This is the first major game project we did at indie game dev school.

A 4-week project in Unity. I pitched the game idea and worked with the rest of my team to develop the full game concept. 

- I made the poster.
- I made most of the environmental art:
  - Underwater flora
  - SpriteShape tiles
  - Underwater fog
  - Trees
  - Mountains
  - Sun
  - Clouds
  - Background art

I set up the post-processing for the level.
I coded the fishing line mechanic.
I made the store boat and the store owner character, "Sleazy Oskar".
