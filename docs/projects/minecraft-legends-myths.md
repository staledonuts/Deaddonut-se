# 'Myths' for Minecraft Legends. 

- Angry Rats
- Ichorous Grove
- Magic Carpet
- Creature Caretaker
- Temple Escape

I worked on all the VFX for the dlcs with over 200 emitter variants using the modified Minecraft bedrock driven JSON particle system.
